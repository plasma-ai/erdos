## Statement

**Theorem 16** (p. 105, quoted). "Let A be a maximal asymptotic nonbasis of
order 2 for the infinite set U. Then A contains arbitrarily long finite
arithmetic progressions."

**Remark** (p. 105). A maximal asymptotic nonbasis of order 2 need not contain
arbitrarily long intervals; the paper's example is the set of all even
integers, which contains no interval of length 2.

## Proof pointer

P. 105. If $A$ has lower asymptotic density zero,
[[additive_bases/erdos_1979_systems_distinct_representatives_minimal_bases_additive/theorem_12|Theorem 15]] gives arbitrarily long intervals; otherwise
Szemerédi's theorem applies.
