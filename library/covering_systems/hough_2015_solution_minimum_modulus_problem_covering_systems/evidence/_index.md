The [checker](verify_hough2015.py) beside this page certifies the finite
numerical claims documented on
[[covering_systems/hough_2015_solution_minimum_modulus_problem_covering_systems/numerical_certificate|the numerical certificate page]],
which proves the enclosure and sieve algorithms and states the command,
expected runtime and failure behavior. It names the source PDF by path in its
certificate and does not read it.
Dependencies are the standard library and the root `tools` package of the
repository environment; every obligation is recorded through the shared
`Checker`, and any failure exits nonzero, including under `python -O`.
