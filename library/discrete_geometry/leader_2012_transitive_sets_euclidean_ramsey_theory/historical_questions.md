***

These are the questions in
Sections 3–5, pp. 15–19 of the arXiv version 1012.1350v1
(December 2010) identified in the
[[discrete_geometry/leader_2012_transitive_sets_euclidean_ramsey_theory/_index|source digest]].
This page records their source meaning. It does not certify that each is
still open on the access date, 5 September 2026.

- **G** (Problem G, p. 15). Prove the fixed-degree block-set assertion (Conjecture E) with
  $m=3$ for the template $112233$. Theorem 3.1 handles $1^r2^s3$, which has only one occurrence
  of its third letter. The duplicated third letter is outside that proof.
  Later work on block sizes must be checked at its own precise quantifiers.
- **H** (Problem H, p. 17). Give an explicit cyclic polygon which is not subtransitive.
  Theorem 4.2 supplies a measure-zero existence argument, not coordinates.
- **I** (Conjecture I, p. 18). Posed as a conjecture, not a problem: there is a cyclic
  quadrilateral which is not subtransitive; the authors further suggest
  that almost none are subtransitive.
  Their separate *Transitive Sets and Cyclic Quadrilaterals*, Journal of
  Combinatorics 2 (2011), 457–462,
  [DOI 10.4310/JOC.2011.v2.n3.a6](https://doi.org/10.4310/JOC.2011.v2.n3.a6),
  addresses these later questions. It is a distinct source rather than
  a proof contained in this 2010 manuscript.
- **J** (Problem J, p. 19). For a Ramsey set $X$, is there a number of colors $k$ for
  which every minimum-cardinality finite $k$-Ramsey witness for $X$ is
  transitive? The alternative discussed in the source restricts to
  inclusion-minimal witnesses whose placement cannot be changed to add
  more copies of $X$ while keeping the existing ones. The
  [[discrete_geometry/leader_2012_transitive_sets_euclidean_ramsey_theory/minimal_witnesses|unit-pair example]]
  proves neither statement for a general target.
- **K** (Problem K, p. 19). Is there an algorithm deciding whether a given finite Euclidean
  set is subtransitive? The paragraph does not specify an encoding or
  computational model for arbitrary real coordinates. No effective
  decidability assertion is inferred from this question.

The source also notes, on p. 5, that its classification and scaled-product
conjectures together would make a set sphere-Ramsey exactly when it is
Ramsey; it poses no separate question about this.
Its sphere-Ramsey definition permits the containing sphere radius to depend
on the color count. It is not the stronger assertion of a monochromatic
copy on the sphere of the set's own intrinsic radius.

On p. 18, the word “trapezia” is used in the cyclic-quadrilateral discussion.
The cited Kříž result concerns cyclic quadrilaterals with a parallel pair of
sides. The passage is not a theorem that arbitrary nonspherical trapezoids
are Ramsey or subtransitive.
