## Statement

Definitions (p. 317). A point set $P$ has *property $E_k$* if for every
$p\in P$ there are $p_1,\dots,p_k\in P$ with
$d(p,p_1)=d(p,p_2)=\dots=d(p,p_k)$. A finite point set is *convex* if it is
the vertex set of a convex polygon.

**Remark 1.2** (p. 317). The paper records two statements, neither proved in
it.

- Danzer (unpublished) has an example showing that there are arbitrarily
  large finite convex sets with property $E_3$.
- Erdős conjectures that no finite convex set has property $E_4$.

## Proof pointer

None: the remark records an unpublished example and a conjecture.

## Bears on

- [[../wiki/problems/distance_problems/E0097/_index|Problem 97]]: the
  conjecture the remark attributes to Erdős, that no finite convex set has
  property $E_4$, is the affirmative answer to the problem's question
  whether every convex polygon has a vertex with no other four vertices
  equidistant from it; Danzer's example concerns the same question with three
  in place of four. The paper proves neither statement.
