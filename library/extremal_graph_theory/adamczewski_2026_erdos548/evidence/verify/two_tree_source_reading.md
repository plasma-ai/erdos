two-color star-sharpness proof. Both concern ordinary, not necessarily

## Source identity and exact consumed interface

The native source digest identifies *A Counting Proof for Erdős Problem
548* (2026), a five-page preliminary exposition supplied by Thomas F.
Bloom and generated from the GPT-6 Astra formal proof. Its source slug
identifies the original proof repository's maintainer, Tom Adamczewski;
it does not attribute the mathematical proof to him.

The digest's selected [canonical PDF][pdf] is held in Git LFS, which records
its digest, and has public source URL
[the site's exposition](https://www.erdosproblems.com/static/548copy.pdf).
Theorem 1 is located on page 1, with its final proof step in §5 on page 5.
These are identities and locators read through native Markdown. This unit's
author, reviewer, grader and documentary rendition author did not inspect
a PDF page or freshly hash that PDF for this unit.

The exact consumed interface is Theorem 1, original lines 15–24:
a fixed tree `T` of order `t >= 2`, a finite simple graph `G` of
order `N >= 1`, and absence of a non-induced copy of that given tree
imply `2e(G) <= (t-2)N`. There is no relation required between `N`
and `t`. The two-tree proof applies this once to each spanning color
graph with `t = n_1` and `t = n_2`. It consumes the sharp edge bound,
not merely the stronger literal threshold hypothesis in the catalog's
wording of #548.

The regular-graph existence argument, star center-degree criterion,
complement degrees, parity and endpoint cases are supplied in the two
reviewed pages. The star page consumes the upper bound within the same
unit. No native L-claim, general-`q` corollary, forum assertion, prior
six-page verdict or external regular-graph existence theorem is consumed.

The premise's linked marked-count and rooted-word proof chain was not
