## Statement

Section 5 is on printed p. 64.

Sierpiński proved in 1933 that $c\not\to(\aleph_1,\aleph_1)^2$: there is a
graph on the real numbers with no uncountable complete subgraph and no
uncountable independent set. Kurepa obtained the same result independently.

In 1954 Erdős asked whether the pairs of real numbers can be divided into
three classes so that every uncountable set of reals contains a pair from
each class. He proved the answer affirmative if $c=\aleph_1$ and could not
decide the question without the continuum hypothesis; he offered a prize
for a decision. Shelah proved it consistent that the answer is negative, in a
model where $c$ is very large. Whether a negative answer is consistent with
$c=\aleph_2$ was not known.

**Source.** P. Erdős, *On some problems in combinatorial set theory*, Publ.
Inst. Math. (Beograd) (N.S.) 57(71) (1995), 61–65; Section 5, printed p. 64.
