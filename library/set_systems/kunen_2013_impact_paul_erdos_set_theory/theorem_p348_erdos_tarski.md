## Statement

Setting (p. 348). The survey translates into modern terms the properties of
a cardinal $\lambda>\omega$ considered by Erdős and Tarski (its reference
[24], On some problems involving inaccessible cardinals, Essays on the
Foundations of Mathematics, Jerusalem, 1961, 50--82), following them in
taking the negation of each property as the large cardinal property:

- $P_1$: some total order on $\lambda$ has no increasing or decreasing
  $\lambda$-sequences;
- $P_2$: $\lambda\not\to(\lambda)^2_2$;
- $P_3$: there is no $\lambda$-complete non-principal ultrafilter on
  $\lambda$;
- $P_4$: some $\lambda$-complete and $\lambda$-distributive boolean algebra
  is not isomorphic to any $\lambda$-complete set algebra;
- $Q$: there is a $\lambda$-Aronszajn tree;
- $R$: some boolean algebra as in $P_4$ is, in addition, $\lambda$-generated
  by a set of size $\lambda$.

**Results reported** (p. 348).

- [24] shows that $P_m$ implies $P_{m+1}$ for $m=1,2,3$, and that $\neg P_1$,
  hence each $\neg P_m$, implies that $\lambda$ is strongly inaccessible.
- For strongly inaccessible $\lambda$, each of $\neg P_1$, $\neg P_2$,
  $\neg Q$, $\neg R$ is equivalent to weak compactness, $\neg P_3$ to
  measurability and $\neg P_4$ to strong compactness. The survey calls this
  well known with hindsight: some implications are in [24] and others were
  later proved by others; [24] proves $P_1\to P_2$ but not $P_2\to P_1$.

**Strong inaccessibility from $\neg Q$** (p. 349). Erdős and Tarski did not
know whether $\neg Q$ or $\neg R$ implies strong inaccessibility; for $\neg Q$
the survey reports that it does not, since by Mitchell (1970) even $\aleph_2$
can satisfy $\neg Q$.

## Proof pointer

None in this survey; the proofs are in [24] and the later papers it cites,
which are not held.
