The data file contains vertex labels, not stored bit indices, and has no
separate label-to-bit field. The frozen reader's e0834-bitmask-v1 contract
requires vertices [1,2,3,4,5,6,7,8,9]; _vertex_mask fixes this exact mapping:

label: 1 2 3 4 5 6 7 8 9
bit:   0 1 2 3 4 5 6 7 8

A blue set B has mask sum(1 << (i-1) for i in B). For an edge mask e and blue
mask b, the edge is monochromatic exactly when e & b is 0 or e. Every mask
0..511 is inspected, without complement reduction. Edge-witness keys must
equal the 22 edge labels; the indexed edge must be the unique monochromatic
edge. Vertex-witness keys must be exactly 1..9, the deleted label cannot remain
blue, and every incident triple is removed whole, not shortened. Three classes
must be nonempty, disjoint and cover the full domain. The derived link removes
bit 0 from each edge containing it and is compared with the ten displayed
pairs. These are the reviewed checker semantics, not a new proof argument.

The bounded ASCII JSON reader caps input at 16,384 bytes and nesting at eight,
rejects duplicate keys and noninteger values, and checks exact shapes and
domains before mathematical evaluation; the result names the input by path (as
reviewed on 2026-09-15 it carried the input digest as input_sha256).
Mathematical failures use explicit raises, not
removable assertions. The file reader requires a regular file and refuses a
final-component symlink; intermediate directory symlinks are not excluded.
Unexpected exceptions cannot become a success result. Tests use only synthetic
and mutated small inputs; they do not open the retained Li input or invoke its
512-assignment calculation.
