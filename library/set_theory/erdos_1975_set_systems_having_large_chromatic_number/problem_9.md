## Statement

**Problem 9** (§11, p. 481). Characterize the (finite) triple systems that
occur in every $\aleph_1$-chromatic triple system on $\omega_1$.

Notation (p. 481). $G_3(\kappa)$ is the class of finite triple systems
that occur in every $\kappa$-chromatic triple system on $\kappa$.

This is an instance of the paper's problem (III) (p. 427), and the
paper's evaluation of the edge density it forces is
[[set_theory/erdos_1975_set_systems_having_large_chromatic_number/corollary_11_14|Corollary 11.14]].
The authors record (p. 481): by Corollary 3.3, $G_3(\omega_1)$ is large,
for example $\mathcal T_0\in G_3(\omega_1)$; by Corollary 11.4,
$\mathcal T_7\notin G_3(\omega_1)$ although
$\aleph_1\to(\aleph_1,\mathcal T_7)^3$; under CH, Theorem 11.6 gives
$\mathcal T_1,\mathcal T_3,\mathcal T_4,\mathcal T_8\notin G_3(\omega_1)$
and Theorem 11.11 gives $\mathcal T_9\notin G_3(\omega_1)$. Here
$\mathcal T_0,\dots,\mathcal T_9$ are special finite triple systems defined
in the paper (list, p. 511). The related problems (pp. 481--482):

- 9/A. Does ZFC prove
  $\mathcal T_1,\mathcal T_3,\mathcal T_4,\mathcal T_8,\mathcal T_9\notin G_3(\omega_1)$?
- 9/B. Is there an $\aleph_1$-chromatic triple system on $\omega_1$
  avoiding both $\mathcal T_1$ and $\mathcal T_9$?
- 9/C. Is there an $\aleph_1$-chromatic triple system on $\omega_1$
  avoiding $\mathcal T_1$, $\mathcal T_3$, $\mathcal T_4$ and $\mathcal T_9$?
- 9/D. If $\mathcal S_1$ and $\mathcal S_2$ are finite triple systems and
  each is avoided by some $\aleph_1$-chromatic triple system on $\omega_1$,
  is there one such system avoiding both?
- 9/E. For $\kappa,\lambda\ge\aleph_0$, is $G_3(\kappa)=G_3(\lambda)$?

**Read depth.** Claims checked: Problem 9, the notation $G_3(\kappa)$, the
remarks before 9/A and the questions 9/A to 9/E were read clause by clause
on the page images of the print.

## Bears on

- [[../wiki/problems/set_theory/E1177/_index|Problem 1177]]: 9/D is the
  problem's second assertion asked only for triple systems on $\omega_1$,
  where the problem places no bound on the vertex set; 9/E asks whether
  the classes $G_3(\kappa)$ agree for all infinite $\kappa$, which concerns
  $\kappa$-chromatic systems on exactly $\kappa$ vertices, while the
  problem's third assertion concerns systems of chromatic number $\kappa$
  of any size. The paper poses both as open.
