# Problem 28

[[problems/additive_bases/_index|..]]

***

**Statement.** If $A\subseteq \mathbb{N}$ is such that $A+A$ contains all but
finitely many integers then $\limsup 1_A\ast 1_A(n)=\infty$.

**Status.** Open.

**Source.** [erdosproblems.com/28](https://www.erdosproblems.com/28), accessed
2026-09-04. Cite as: T. F. Bloom, Erdős Problem #28,
https://www.erdosproblems.com/28.

**References.**

- [Gu04] Guy, Richard K., Unsolved problems in number theory. Third edition,
  Problem Books in Mathematics, Springer, New York (2004), xviii+437 pp.;
  section C9 "Packing sums of pairs", printed p. 177: the Erdős--Turán
  conjecture that $f(n)>0$ for all large $n$ forces $\limsup f(n)=\infty$,
  with the prize offer.
  Library home:
  [[../library/number_theory/guy_2004_unsolved_problems_number_theory/_index|guy_2004_unsolved_problems_number_theory]].

[formal-conjectures](https://github.com/google-deepmind/formal-conjectures/blob/main/FormalConjectures/ErdosProblems/28.lean).
