# Problem 1145

[[problems/additive_bases/_index|..]]

***

**Statement.** Let $A=\{1\leq a_1<a_2<\cdots\}$ and $B=\{1\leq b_1<b_2<\cdots\}$
be sets of integers with $a_n/b_n\to 1$.

If $A+B$ contains all sufficiently large positive integers then is it true that
$\limsup 1_A\ast 1_B(n)=\infty$?

**Formulation.** The site's wording as accessed. On this page
$1_A\ast 1_B(n)$ is read as the number of ordered pairs $(a,b)\in A\times B$
with $a+b=n$, so the question asks whether, once every sufficiently large
positive integer has such a representation, the representation count is
unbounded; this reading is made here, not on the site.

**Status.** Open.

**Source.** [erdosproblems.com/1145](https://www.erdosproblems.com/1145),
accessed 2026-09-04. Cite as: T. F. Bloom, Erdős Problem #1145,
https://www.erdosproblems.com/1145.

**Formalization.** Statement in
[formal-conjectures](https://github.com/google-deepmind/formal-conjectures/blob/main/FormalConjectures/ErdosProblems/1145.lean).
