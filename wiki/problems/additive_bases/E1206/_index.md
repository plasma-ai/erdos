# Problem 1206

[[problems/additive_bases/_index|..]]

***

**Statement.** Does $\{1,2^3,\ldots,N^3\}$ contain a Sidon set of size $\gg N$?

Is there an infinite set $A\subset \mathbb{N}$ of positive density such that
$\{a^3 : a\in A\}$ is a Sidon set?

**Status.** Open.

**Source.** [erdosproblems.com/1206](https://www.erdosproblems.com/1206),
accessed 2026-09-04. Cite as: T. F. Bloom, Erdős Problem #1206,
https://www.erdosproblems.com/1206.
