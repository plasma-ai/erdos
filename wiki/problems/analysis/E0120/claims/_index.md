[[problems/analysis/E0120/claims/2026_10_05_openai|2026_10_05_openai]]: A release manuscript claiming that for each fixed ratio q in (0,1) and each

affine copy of {q^n : n >= 1} with nonzero dilation; pending, with only the
ratio q = 1/2 formally verified.
