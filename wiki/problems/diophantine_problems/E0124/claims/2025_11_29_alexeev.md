**Claim.** Let $d_1,\ldots,d_r\ge2$ be integers, repetition allowed, with
$\sum_i1/(d_i-1)\ge1$. Then every nonnegative integer is $a_1+\cdots+a_r$,
where each $a_i$ has only the digits $0$ and $1$ in base $d_i$, that is
$a_i\in P(d_i,0)$ in the notation of
[[problems/diophantine_problems/E0124/_index|Problem 124]], with $a_i=0$
allowed. The Lean file linked above proves this as `erdos_124`, beside two
versions of the formal-conjectures statement of the problem: for every
`k`, every `d : Fin k → ℕ` with `2 ≤ d i` for all `i` and
`1 ≤ ∑ i, (1 : ℚ) / (d i - 1)`, and every `n`, there is `a : Fin k → ℕ` with
the base-`d i` digits of each `a i` in `{0, 1}` and `n = ∑ i, a i`. The
statement is stronger than the problem's first question, which asks only
about sufficiently large integers and about distinct bases $d_i\ge3$. Boris
Alexeev posted the result on the site's thread on 2025-11-29, writing that
Aristotle from Harmonic found the proof working only from the formal
statement. The file's header says the same and names no human author of
the proof; the formal-conjectures statement file, at its commit of
2026-09-18 (the `record` link), marks its first question `erdos124.zero`
as `research solved`, "solved by Boris Alexeev using Aristotle", with no
`formal_proof` attribute. The argument was not reconstructed in this
corpus.

**Covers.** The first question, read as the problem page's corrected
Statement, with $\sum_i1/(d_i-1)\ge1$: yes, and for every integer, not
only the sufficiently large ones. Not covered: the second question, the one
under the gcd condition with powers of exponent at least $k\ge1$, which the
Lean file does not address.
