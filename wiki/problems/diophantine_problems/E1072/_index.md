# Problem 1072

[[problems/diophantine_problems/_index|..]]

***

**Statement.** For any prime $p$, let $f(p)$ be the least integer such that
$f(p)!+1\equiv 0\pmod{p}$.

Is it true that there are infinitely many $p$ for which $f(p)=p-1$? Is it true
that $f(p)/p\to 0$ for almost all $p$?

**Status.** Open.

**Source.** [erdosproblems.com/1072](https://www.erdosproblems.com/1072),
accessed 2026-09-04. Cite as: T. F. Bloom, Erdős Problem #1072,
https://www.erdosproblems.com/1072.
