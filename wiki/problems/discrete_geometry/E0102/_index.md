# Problem 102

[[problems/discrete_geometry/_index|..]]

***

**Statement.** Let $c>0$ and $h_c(n)$ be such that for any $n$ points in
$\mathbb{R}^2$ such that there are $\geq cn^2$ lines each containing more than
three points, there must be some line containing $h_c(n)$ many points. Estimate
$h_c(n)$. Is it true that, for fixed $c>0$, we have $h_c(n)\to \infty$?

**Status.** Open.
