# problems/distance_problems/E0754/claims

[[problems/distance_problems/E0754/_index|..]]

[[problems/distance_problems/E0754/claims/2011_08_24_swanepoel|2011_08_24_swanepoel]]: Swanepoel proves that n points in four-dimensional space, each with a chosen
distance, have at most n^2/2 + O(n) pairs at the chosen distances, so a set
in which every point has f(n) equidistant points has f(n) <= n/2 + O(1).
