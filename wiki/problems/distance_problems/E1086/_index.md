# Problem 1086

[[problems/distance_problems/_index|..]]

***

**Statement.** Let $g(n)$ be minimal such that any set of $n$ points in
$\mathbb{R}^2$ contains the vertices of at most $g(n)$ many triangles with the
same area. Estimate $g(n)$.

**Status.** Open.

accessed 2026-09-04. Cite as: T. F. Bloom, Erdős Problem #1086,
