# problems/divisors/E0844/claims

[[problems/divisors/E0844/_index|..]]

[[problems/divisors/E0844/claims/2025_07_01_weisenberg|2025_07_01_weisenberg]]: Desmond Weisenberg shows that a maximal set contains every non-squarefree
number and that Chvátal's 1974 theorem makes the even squarefree numbers
the largest pairwise non-coprime set of squarefree numbers, answering yes.

[[problems/divisors/E0844/claims/2025_07_02_alexeev_mixon_sawin|2025_07_02_alexeev_mixon_sawin]]: Alexeev, Mixon and Sawin prove that the squarefree graph's vertices split
into cliques each holding one even vertex, so the even vertices are a
maximum independent set and the Erdős–Sárközy guess is correct.
