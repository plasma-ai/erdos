[[problems/factorials_binomials/E0404/claims/1976_01_01_lin|1976_01_01_lin]]: Lin's Bell Laboratories memorandum shows that no sum of distinct factorials
beginning with 2! is divisible by 2^255, so f(2,2) is at most 254 and the
first question has the answer yes at a = 2, p = 2; reported by the site.

[[problems/factorials_binomials/E0404/claims/2026_07_07_kitamura|2026_07_07_kitamura]]: Kenta Kitamura's repository computes f(a,2) exactly for every a from 1 to 256,
each value certified by a witness and an exhaustive finite search; prepared
with Codex 5.5, ChatGPT 5.5 Pro and Claude Code (Fable 5).

[[problems/factorials_binomials/E0404/claims/2026_07_08_kitamura|2026_07_08_kitamura]]: Kenta Kitamura's companion repository computes exact values of f(a,p) for some
pairs with p = 3, 5, 7, 11, 13, such as f(3,3) = 3; prepared with Codex,
