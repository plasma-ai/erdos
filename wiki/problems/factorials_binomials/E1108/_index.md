# Problem 1108

[[problems/factorials_binomials/_index|..]]

***

**Statement.** Let

$$
A = \left\{ \sum_{n\in S}n! : S\subset \mathbb{N}\textrm{ finite}\right\}.
$$

If $k\geq 2$, then does $A$ contain only finitely many $k$th powers? Does it
contain only finitely many powerful numbers?

**Status.** Open.

**Source.** [erdosproblems.com/1108](https://www.erdosproblems.com/1108),
accessed 2026-09-04. Cite as: T. F. Bloom, Erdős Problem #1108,
https://www.erdosproblems.com/1108.
