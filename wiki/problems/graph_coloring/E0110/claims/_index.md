# problems/graph_coloring/E0110/claims

[[problems/graph_coloring/E0110/_index|..]]

[[problems/graph_coloring/E0110/claims/2002_12_04_komjath_shelah|2002_12_04_komjath_shelah]]: Komjáth and Shelah (J. Graph Theory 2005) prove it consistent with ZFC that
for every increasing f some graph of chromatic number aleph one has every
n-chromatic subgraph on at least f(n) vertices; a yes answer is unprovable.

[[problems/graph_coloring/E0110/claims/2019_02_21_lambie_hanson|2019_02_21_lambie_hanson]]: Lambie-Hanson's theorem that for every function f there is a graph of
chromatic number aleph_1 whose subgraphs of chromatic number k >= 3 all have
at least f(k) vertices, answering the question no in ZFC; refereed in 2020.
