# Sequences and Densities of Integers

[[problems/_index|..]]

[[problems/integer_sequences/E0012/_index|E0012/]]: Asks how large an infinite
set with no element dividing the sum of two larger elements can be, in counting,
density and reciprocal-sum terms; the first two questions have 2026 claimed
answers, the reciprocal sum is open.

[[problems/integer_sequences/E0013/_index|E0013/]]: Asks whether a subset of the
first N integers with no element dividing the sum of two larger elements has
size at most N over 3 plus a constant; proved by Bedert in 2023, with the
ceiling of N over 3 exact for large N.

[[problems/integer_sequences/E0025/_index|E0025/]]: Asks whether the integers
avoiding a chosen residue class for each modulus in an increasing sequence
always have a logarithmic density.

[[problems/integer_sequences/E0038/_index|E0038/]]: Asks whether a set that is
not an additive basis can still always supply a shift raising the count of any
set of Schnirelmann density strictly between 0 and 1 by a positive fraction
depending on the density; proved in 2026.

[[problems/integer_sequences/E0121/_index|E0121/]]: Asks whether the largest
subset of the first N integers with no five (or no fixed odd number, at least
five, of) distinct elements multiplying to a square has size nearly N; Tao
(2024) disproved it for every size at least 4.

[[problems/integer_sequences/E0131/_index|E0131/]]: Estimates the largest subset
of the first N integers in which no element divides the sum of any distinct
others; the displayed root-N question is answered no, and the order carries one
unreviewed claim of exponent 1/5.

[[problems/integer_sequences/E0145/_index|E0145/]]: Asks whether the average of
the alpha-th power of gaps between consecutive squarefree numbers up to x has a
limit for every non-negative alpha.

[[problems/integer_sequences/E0208/_index|E0208/]]: Bounds the gaps between
consecutive squarefree numbers, asking whether they are smaller than any fixed
power, and whether a sharp logarithmic bound holds.

[[problems/integer_sequences/E0220/_index|E0220/]]: Asks whether the sum of

consecutive integers that are sums of two squares, from above and below.

[[problems/integer_sequences/E0235/_index|E0235/]]: Asks whether the

[[problems/integer_sequences/E0253/_index|E0253/]]: Asks whether a sequence with
ratios tending to one whose distinct subset sums meet every arithmetic
progression infinitely often represents all large integers.

[[problems/integer_sequences/E0254/_index|E0254/]]: Asks whether a set that
grows in every dyadic range and has divergent sums of distances to the nearest
integer for every angle represents all large integers as distinct sums.

[[problems/integer_sequences/E0329/_index|E0329/]]: The largest possible value
of the limiting ratio of the counting function of an infinite Sidon set to the
square root of N.

[[problems/integer_sequences/E0451/_index|E0451/]]: Estimates the least integer

[[problems/integer_sequences/E0460/_index|E0460/]]: Asks whether the reciprocal

[[problems/integer_sequences/E0467/_index|E0467/]]: Asks whether, for large x,

[[problems/integer_sequences/E0471/_index|E0471/]]: Asks whether some finite

[[problems/integer_sequences/E0472/_index|E0472/]]: Asks whether some starting

[[problems/integer_sequences/E0481/_index|E0481/]]: Asks whether iterating a
