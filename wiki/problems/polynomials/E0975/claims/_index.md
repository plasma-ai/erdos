# problems/polynomials/E0975/claims

[[problems/polynomials/E0975/_index|..]]

[[problems/polynomials/E0975/claims/1963_01_01_hooley|1963_01_01_hooley]]: Hooley's Theorem 2 of 1963: for a nonzero integer a with -a not a square,
the sum of d(n^2 + a) over n <= x is A_2(a) x log x + A_3(a) x + O(x^(8/9)
log^3 x), the asymptotic of Problem 975 for the quadratics x^2 + a; refereed.

[[problems/polynomials/E0975/claims/1995_05_01_mckee|1995_05_01_mckee]]: McKee's 1995 theorem: for x^2 + bx + c with discriminant b^2 - 4c < 0,
the sum of d(n^2 + bn + c) over n <= x is lambda x log x + O(x), with lambda
given by a Hurwitz class number; Problem 975 for these quadratics, refereed.

[[problems/polynomials/E0975/claims/1997_01_30_mckee|1997_01_30_mckee]]: McKee's 1997 note: for an^2 + bn + c with b^2 - 4ac < 0 and gcd(a, b^2 -
4ac) = 1, the sum of d(an^2 + bn + c) over n <= x is C x log x + O(x);
Problem 975 for these quadratics, in a proceedings volume.

[[problems/polynomials/E0975/claims/1999_01_01_mckee|1999_01_01_mckee]]: McKee's 1999 theorem: for x^2 + bx + c with b^2 - 4c positive and not a
square, the sum of d(n^2 + bn + c) over n <= x is lambda x log x + O(x),
lambda given by a weighted class number; Problem 975 there, refereed.
