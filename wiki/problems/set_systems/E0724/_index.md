# Problem 724

[[problems/set_systems/_index|..]]

***

**Statement.** Let $f(n)$ be the maximum number of mutually orthogonal Latin
squares of order $n$. Is it true that

$$
f(n) \gg n^{1/2}?
$$

**Status.** Open.

**Source.** [erdosproblems.com/724](https://www.erdosproblems.com/724), accessed
2026-09-04. Cite as: T. F. Bloom, Erdős Problem #724,
https://www.erdosproblems.com/724.
