# Problem 1175

[[problems/set_theory/_index|..]]

***

**Statement.** Let $\kappa$ be an uncountable cardinal. Must there exist a
cardinal $\lambda$ such that every graph with chromatic number $\lambda$
contains a triangle-free subgraph with chromatic number $\kappa$?

**Status.** Open.

accessed 2026-09-04. Cite as: T. F. Bloom, Erdős Problem #1175,
https://www.erdosproblems.com/1175.
