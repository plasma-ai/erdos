[[problems/unit_fractions/E0302/claims/2025_03_25_cambie|2025_03_25_cambie]]: Cambie's construction, recorded in the site's commentary, of a set of
density 5/8 with no relation 1/a = 1/b + 1/c among distinct elements; it
shows f(N) >= (5/8 + o(1))N, so f(N) is not (1/2 + o(1))N.

[[problems/unit_fractions/E0302/claims/2025_08_11_van_doorn|2025_08_11_van_doorn]]: Van Doorn's note proves that every subset of the first n integers of size
at least 9n/10 plus a cube of a logarithm plus one contains distinct x, y,
z with 1/x + 1/y = 1/z, so f(N) <= (9/10 + o(1))N for Problem 302.
